1. Популярные сервисы с открытыми API

1. CoinGecko
Мой выбор
- Бесплатный Demo API: 10 000 запросов в месяц.
- До 100 запросов в минуту.
- Цена, капитализация, изменение за 24 часа.
- Для Demo требуется бесплатная регистрация.
Сайт и документация · API Docs.
CoinGecko API
url = "https://api.coingecko.com/api/v3/simple/price"

2. Binance
Без API-ключа
- Публичные рыночные данные.
- Текущая цена и изменение за 24 часа.
- Не нужна регистрация.
- Данные конкретной биржи, а не средняя цена всего рынка.
Документация.
Binance Developer Docs+1
url = "https://data-api.binance.vision/api/v3/ticker/price"
url = "https://api.binance.com/api/v3/ticker/price"
Для вашего текущего приложения (простой список из 20 монет) переход на Binance API усложнит код.
Вам придётся либо делать 20 отдельных запросов, либо использовать более сложные эндпоинты
 для получения всех цен сразу (например, /api/v3/ticker/price без параметра symbol
  возвращает все пары, но это большой объём данных, который нужно фильтровать).

3. CoinMarketCap
- Публичные endpoints без ключа.
- Бесплатный Basic API с регистрацией.
- Цены и рыночная статистика.
Сайт API.
CoinMarketCap+1
url = "https://pro-api.coinmarketcap.com/public-api/v3/cryptocurrency/listings/latest"
